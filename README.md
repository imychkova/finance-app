# Наші гроші — трекер витрат

PWA (телефон + веб) → Google Apps Script → Google Sheets.
Етап 1: ручне внесення витрат, історія, редагування, зведення за тижнями/місяцями/роками.

```
docs/         сайт (PWA): index.html, app.js, style.css, sw.js … (назва `docs` потрібна для GitHub Pages)
apps-script/  Code.gs + appsscript.json — API, живе всередині таблиці
dev/          mock-server.js — локальний імітатор API для перевірки інтерфейсу
```

## Розгортання (один раз, ~10 хвилин)

### 1. Таблиця і API
1. Створи нову Google-таблицю (назва, наприклад, «Фінанси»).
2. **Розширення → Apps Script**. Встав вміст `apps-script/Code.gs` у `Code.gs`.
3. **Project Settings** (шестерня) → увімкни «Show appsscript.json manifest file» → встав вміст `apps-script/appsscript.json`.
4. У **Project Settings → Script properties** додай `ACCESS_CODE` = довгий випадковий код (його вводитимете у застосунку; нікому не показуй).
5. Вибери функцію `setup` → **Run**, дозволь доступ. З'являться вкладки `Transactions`, `Налаштування`, `Тижні`, `Місяці`, `Роки`.
6. У вкладці `Налаштування` заміни «Я» / «Yasilda» на ваші імена (список «Хто»). Категорії та джерела теж можна міняти там.
7. **Deploy → New deployment → Web app**: Execute as **Me**, Who has access **Anyone**. Скопіюй адресу `…/exec`.

> Після будь-яких змін у `Code.gs` треба робити **Deploy → Manage deployments → Edit → New version**, інакше працює стара версія.

### 2. Сайт
**GitHub Pages:** створи публічний репозиторій, запуш код, потім Settings → Pages → Source: гілка `main`, папка `/docs`. Адреса буде `https://<логін>.github.io/<репозиторій>/`.
(Альтернатива — Netlify: перетягни папку `docs` на app.netlify.com/drop.)

### 3. Телефон
1. Відкрий адресу сайту. Введи адресу `…/exec` і `ACCESS_CODE` — це зберігається лише на цьому пристрої.
2. iPhone: Safari → «Поділитися» → «На екран Додому». Android: меню Chrome → «Установити застосунок».

## Як це працює
- `Transactions` — єдине джерело даних (одна витрата = один рядок; допоміжні колонки `Тиждень`/`Місяць`/`Рік` заповнюються автоматично).
- `Тижні`, `Місяці`, `Роки` — зведення формулами, оновлюються самі. Ліворуч сума за період, праворуч розбивка за категоріями.
- Без зв'язку витрата кладеться в чергу на телефоні й відправляється, коли він знову онлайн. Дублів не буде (кожен запис має унікальний id).
- Усі запити — POST, код доступу не потрапляє в адресу.

## Локальна перевірка інтерфейсу

```bash
node dev/mock-server.js
```

Відкрий http://localhost:8787, API: `http://localhost:8787/api`, код: `test`. Дані зберігаються лише в пам'яті сервера.

## Автодеплой
- Сайт: GitHub Pages оновлюється сам після пушу в `main`.
- Apps Script: `.github/workflows/deploy-apps-script.yml` при змінах у `apps-script/` пушить код через `clasp` і оновлює розгортання. Потрібні секрети репозиторію `CLASPRC_JSON`, `SCRIPT_ID`, `DEPLOYMENT_ID` (ключі ніколи не коміть).

## План (список покупок і справ)
Вкладка «План» у застосунку й у таблиці (`План` створюється сама). Рядки за категоріями: додати, змінити текст і суму, відмітити виконаним, видалити. Працює лише онлайн.
